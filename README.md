# 3D Sales Analytics Dashboard

## 📊 Overview
A complete Data Analyst project with 3D visualizations, predictions and business insights.

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Plotly (3D charts)
- Streamlit (Dashboard - coming soon)

## ✨ Features
- ✅ 1000 rows sales dataset
- ✅ 7 different 3D charts
- ✅ India state-wise sales map
- ✅ Next month sales prediction
- ✅ Auto insights (top products, regions, etc.)
- ✅ KPI summary
